# WDD 231 Starting Template Repository

This repository provides the starter files and structure for **WDD 231 (Web Frontend Development)** assignments and activities.

**Author:** Bryan Alex Bravo Medina
**GitHub Pages:** https://akherox.github.io/wdd231/

## Purpose

Use this template as the foundation for course projects and practice work, focused on dynamic websites with HTML, CSS, and JavaScript, accessibility, performance, and basic API use.

## Includes

- Starter HTML files
- CSS files (`styles/`)
- JavaScript files (`scripts/`)
- Images (`images/`)

## Notes

This template is intended for educational use and should be expanded as needed for course work.
